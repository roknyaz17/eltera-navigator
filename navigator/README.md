# Eltera Navigator

Реестр вахтовых позиций: подбор для менеджера, карточка позиции, текст кандидату,
админ-панель автопроверки заявок и настройки контрагентов.

Статический фронтенд без бандлера: страницы открываются напрямую, сборка не требуется.

## Запуск

    cd navigator
    cp .env.example .env
    npm start

Открыть http://127.0.0.1:5173 — это экран входа.

Демо-учётная запись: `anna.kuznetsova@romashka.ru` / `eltera2026`.
Пароль администратора в разделе «Админ»: `1207`.

Без Node.js работает любой статический сервер из корня папки:

    python3 -m http.server 5173

## Проверка и сборка

    npm run check    # все локальные ссылки разрешаются, секретов в пакете нет
    npm run build    # прогон check + копия отдаваемых файлов в dist/

## Страницы

- `index.html` — вход по единой учётной записи Eltera, дальше сразу в навигатор
- `navigator.html` — подбор и админ-панель

## Единая учётная запись

`eltera/account.js` — один store на localStorage: одна почта и один пароль на
Навигатор, кабинет Eltera с оценками и CRM Shellix. Сессия общая: вход в одном
продукте открывает остальные без повторного ввода пароля. Смена почты или пароля
обновляет запись и разлогинивает все три системы.

При переносе на сервер вход заменяется серверной сессией: `AUTH_PASSWORD_HASH`
и `ADMIN_PASSWORD_HASH` из `.env`, паролей в коде не остаётся.
